# Budget vs Actual Dashboard

## Project Overview

The **Budget vs Actual Dashboard** is an Excel-based financial analysis project that compares planned budget amounts against actual spending across departments, categories, and monthly reporting periods.

This project demonstrates Excel-based financial reporting, variance analysis, dashboard creation, data organization, and business performance analysis using a mock financial dataset.

## Purpose

Budget vs actual analysis helps show whether spending is aligned with planned financial expectations. This workbook provides a simple way to track budget performance, identify over-budget and under-budget areas, and summarize financial trends through Excel tables, formulas, and dashboard visuals.

## Tools Used

- Microsoft Excel
- Excel formulas
- Summary tables
- Dashboard charts
- KPI cards
- Conditional formatting
- Mock financial dataset

## Workbook Tabs

### Dashboard

Provides a high-level summary of budget performance using KPI cards and charts.

### Budget vs Actual Data

Contains the mock financial dataset used for the analysis, including departments, categories, budgeted amounts, actual amounts, variance, variance percentage, and status.

### Monthly Summary

Summarizes budgeted amount, actual spending, and variance by month.

### Category Summary

Summarizes budget performance by spending category.

### Lists

Contains reference values used in the workbook.

## Key Features

- Budget vs actual comparison
- Variance calculations
- Variance percentage calculations
- Monthly financial summary
- Category-level financial summary
- Dashboard KPIs and charts
- Over-budget and under-budget status tracking
- Organized mock financial dataset
